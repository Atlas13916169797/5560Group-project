# Group 8 飞机数据读取结果

已实际使用本机 MATLAB R2025b Update 7 执行 `FlightDataAircraft8.p` 并加载 `ICsAircraft8_200knts_300ft.mat`。数值来自 Group 8 数据，不是默认示例飞机。未进行重新配平、线性化或控制器设计。

## 1. 文件与读取方法

- 原参数函数：`Group8_AircraftData/Group8_AircraftData/FlightDataAircraft8.p`。
- 原初始条件：同目录 `ICsAircraft8_200knts_300ft.mat`，包含 X0（12×1）和 U0（5×1）。
- `.p` 是 MATLAB P-code，可以调用得到返回结构，但不是可直接阅读的 MATLAB 源码。
- 返回结构包括 `I`、`Geo`、`Prop`、`CntrlLimit`、`Aero` 五组。
- 返回结构中没有实际飞机型号或制造商名称，因此不能据此确定真实机型。

## 3. 初始飞行状态

按仿真框架函数说明，状态顺序为 `[u,v,w,p,q,r,phi,theta,psi,Xe,Ye,Ze]`。

| 状态 | MAT 原值 | 单位/解释 |
|---|---:|---|
| u | 102.886915357347 | m/s，机体系纵向速度 |
| v | 0 | m/s，机体系侧向速度 |
| w | 0.472432270445 | m/s，机体系垂向速度；不等于地面垂直速度 |
| p | 0 | rad/s |
| q | 0 | rad/s |
| r | 0 | rad/s |
| phi | 0 | rad |
| theta | 0.004591730139324 | rad，约 0.263086758° |
| psi | 0 | rad |
| Xe | 0 | m |
| Ye | 0 | m |
| Ze | -91.44 | m，按框架高度 = -Ze，即 91.44 m = 300 ft |

由原值计算：

- 速度模长 V = sqrt(u²+v²+w²) = **102.888 m/s = 199.99827 knots**，对应文件名中的 200 knots。
- 迎角 alpha = atan2(w,u) = **0.263086758°**。
- 侧滑角 beta = asin(v/V) = **0°**。
- theta 与 alpha 相等，在该姿态与速度下对应近似水平飞行的初始运动学条件；不能把 w = 0.4724 m/s 解释成爬升率。
- 此次只读出给定初始点，未求解状态导数残差，因此没有独立验证其动力学配平精度。

## 4. 初始操纵输入与限位

按框架说明，输入顺序为 `[dt,de,da,dr,df]`，即油门、升降舵、副翼、方向舵、襟翼。

| 操纵量 | 原值 | 便于理解的单位 |
|---|---:|---|
| 油门 dt | 0.770316669125977 | 77.0316669% |
| 升降舵 de | 0.013370521759903 rad | +0.766074467° |
| 副翼 da | 0 rad | 0° |
| 方向舵 dr | 0 rad | 0° |
| 襟翼 df | 0 rad | 0° |

`CntrlLimit.Lower/Upper` 各有四个元素，与前四个输入对应：

| 操纵量 | 数据下限 | 数据上限 | 项目使用说明 |
|---|---:|---:|---|
| 油门 | 0 | 1 | 绝对油门范围 0–100% |
| 升降舵 | -25° | +25° | 纵向任务未另给更严格数值，可据本组数据检查 |
| 副翼 | -25° | +25° | 项目任务书明确要求 ±20°，验收按更严格的 ±20° |
| 方向舵 | -25° | +25° | 本组数据给出的限位 |

四个上下限未提供襟翼限位，也未提供舵速限制，不能自行把其他讲义示例当作本机数据。

线性控制器通常输出配平增量，非线性模型需要绝对操纵量：`U = U0 + deltaU`。限位应施加于绝对操纵量。例如升降舵配平为 +0.766074°，其可用增量约为 [-25.766074°, +24.233926°]；油门增量可用范围约为 [-0.770317, +0.229683]。

## 6. 对纵向项目的直接意义

- `Iyy`、`S`、`c` 与 Cm 系列参数直接影响俯仰动力学。
- `Cma < 0`、`Cmq < 0` 在通常符号约定下分别体现恢复性俯仰刚度与俯仰阻尼；这些符号不能替代完整系统极点稳定性分析。
- `Cmde < 0` 说明正升降舵增量对俯仰力矩的直接作用为负，须结合框图和模型响应确认控制器符号。
- CL 系列和阻力参数影响升力、迎角、空速及垂直速度之间的关系。
- 初始油门已经是 77.03%，向上只剩约 22.97 个百分点余量，大爬升指令的自动油门饱和值得关注。
- 数据本身没有提供 Alon、Blon 或 G(q←de)、G(Vs←de)、G(u←dt)。这些需要在当前初始条件下调用非线性模型进行线性化后求得。

## 7. MATLAB 兼容映射与后续读取

数据包 Note.txt 明确要求旧字段兼容转换；其示例中的 Aircraft5 应替换为实际 Group 8 函数：

```matlab
FlightData = FlightDataAircraft8();
FlightData.Geometric = FlightData.Geo;
FlightData.Inertial = FlightData.I;
FlightData.Propeller = FlightData.Prop;
load('ICsAircraft8_200knts_300ft.mat', 'X0', 'U0');
```

导出的 `Group8_readable_data.mat` 已包含：

- `FlightDataOriginal`：原函数完整返回结构；
- `FlightData`：添加兼容字段后的结构；
- `InitialConditions.X0`、`InitialConditions.U0`：原初始向量。

```matlab
D = load('Group8_readable_data.mat');
FlightData = D.FlightData;
X0 = D.InitialConditions.X0;
U0 = D.InitialConditions.U0;
```

`Group8_raw_data.json` 保留原始数值，`Group8_parameters.csv` 可用 Excel 打开；读取脚本为上一级目录的 `read_group8_aircraft.m`。
