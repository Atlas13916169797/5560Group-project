# Group 8：升降舵到俯仰角速度传递函数

已在 MATLAB 中从本组纵向四状态模型提取任务书 Task 1 所需的 G(q←delta_e)。设计点为约 200 knots、300 ft，采用固定高度的纵向四状态近似。

## 定义与构造

状态为 `[delta_u,delta_w,delta_q,delta_theta]`，输入为升降舵配平增量 delta_e（rad），输出为 delta_q（rad/s）。

```text
Cq = [0 0 1 0]
Dq = 0
Bq = Blon(:,2)
Gqde(s) = Cq * inv(s*I - Alon) * Bq
```

没有加入控制器、执行器或传感器模型。该函数是飞机本体的开环 plant，不是闭环跟踪函数。

## ZPK 的实系数因式表达

```text
                 -88.1969391217 s (s + 4.70497807288) (s + 0.0634736546623)
Gqde(s) = ----------------------------------------------------------------------
          (s² + 8.46272333081 s + 28.7970620659)
          × (s² + 0.0607942130633 s + 0.00689805045527)
```

零点：0、-4.70497807288、-0.0634736546623。

极点：-4.23136166541 ± 3.30040005491i，以及 -0.0303971065317 ± 0.0772920847808i。

ZPK 增益：-88.1969391217。

## 多项式表达

```text
                -88.1969391217 s³ - 420.562846719 s² - 26.3393238219 s
Gqde(s) = ----------------------------------------------------------------
          s⁴ + 8.52351754387 s³ + 29.3184447217 s² + 1.80907101936 s
          + 0.198643587094
```

以上打印数值经过舍入；Gqde.mat 与 Gqde.json 保存完整计算精度。

## 检查与解释

- 将传递函数与 Cq*(jwI-Alon)^(-1)*Bq 在 1e-4 至 1e4 rad/s 的 501 个频率点比较，最大相对误差约 1.78e-13。
- 另由 Cayley-Hamilton / Markov 递推独立构造多项式，频响最大相对误差约 7.20e-9。
- 原始数值零点之一约为 +2.40e-16。由 q=d(theta)/dt、A 可逆、D=0 可知应有精确原点零点；程序核对结构及 DC 增益后仅将该浮点残差归零。原始版本 Gqde_raw 也已保存，没有做一般零极点消去。
- 四个极点与 A_lon 特征值一致，均位于左半平面。
- DC 增益为零，意味着该稳定开环模型对恒定升降舵输入的俯仰角速度最终回到零，不能把它理解为飞机俯仰角一直匀速改变。
- 高频首项约为 -88.19694/s，反映本模型正升降舵增量对俯仰角加速度的直接负作用。后续闭环必须正确设置反馈与补偿器符号。

## 使用

```matlab
load('Gqde.mat','Gqde');
sisotool(Gqde)
```

MAT 文件还包含原始 TF、状态空间 sys_q、Aq/Bq/Cq/Dq、零极点与多项式系数。此处尚未设计 q 内环补偿器，下一步才是任务书要求的至少三种补偿器方案。
