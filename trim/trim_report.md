# Group 8 配平检查

结论：**提供的 200 knots / 300 ft 初始条件通过本次配平检查，无需在此阶段重新配平，可以保留为下一步线性化的设计点。**

## 方法与范围

实际使用 MATLAB R2025b Update 7，调用本目录 Group 8 参数与课程非线性模型。旧字段已转换为当前框架所需的 Geometric / Inertial / Propeller。

1. 零阵风，固定原 U0，迭代求解 aero5560_aero 与 aero5560_motion 的状态导数一致性。
2. 检查动力学、姿态与水平直线运动条件。地面 Xe 前进速度不要求为零。
3. 原始 X0、U0 不作修改，在完整 12 状态非线性模型中积分 60 s，无指令阶跃、无控制器。
4. ode45 使用 RelTol=1e-9、AbsTol=1e-11、MaxStep=0.05 s；再以 RelTol=1e-10、AbsTol=1e-12、MaxStep=0.025 s 复核，输出采样间隔 0.1 s。

## 对项目的意义与下一步

当前初始点是数值上平衡的基准，可用于求 A/B 与纵向输出模型；无需为了消除不存在的漂移修改升降舵或油门。

**本次检查不证明飞机对扰动稳定。** 即使飞机存在不稳定模态，精确平衡点在无扰动下也可以保持不动。下一步仍需数值线性化、检查特征值，并用小幅操纵输入对比线性/非线性响应，然后提取 G(q←δe) 开始内环设计。
